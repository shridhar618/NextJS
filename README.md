# TypeScript & Next.js Practice

Practice code for learning TypeScript and the Next.js App Router.

## Contents

| Path | Topics |
|---|---|
| `hello.ts`, `array.ts`, `interface.ts`, `props.ts`, `props2.ts`, `assignment.ts`, `program2.ts` | TypeScript basics: types, arrays, interfaces, typed props |
| `env-local/` | Next.js app using environment variables (`.env.local`) |
| `second-app/` | Next.js App Router: nested routes (`/about`, `/student`), layouts, and route-level and global error boundaries |
| `int.py`, `singly.py` | Small Python practice scripts |

## Running

```bash
# TypeScript files
npx tsc hello.ts && node hello.js

# Next.js apps
cd second-app
npm install
npm run dev
```

## Tech stack

TypeScript · Next.js (App Router) · React · Tailwind CSS
